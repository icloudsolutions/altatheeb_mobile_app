# EMS — Doc changes summary (v1.6 → v1.7)

| File | Before | After | Why |
|------|--------|-------|-----|
| `EMS_IMPLEMENTATION_MASTER_PROMPT.md` | v1.5+, generic stack guidance, open decisions | **v1.7**: locked stack picks (FastAPI / React / Flutter / new Odoo addon), explicit env-var contract, security model, full REST surface, webhook catalogue v0, first-sprint backlog, definition-of-done | Move from "what to build" to "what is being built"; remove ambiguity that was blocking implementation. |
